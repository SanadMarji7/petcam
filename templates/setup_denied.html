This page shows both secret keys, so it only opens with the access token the server printed when it started. The token is not in this link.

Server started with Docker (deploy/): in the deploy directory run ./show-pairing.sh to print both QR codes in the terminal, or find the link with docker compose logs petcam | grep 'Pairing page' and open its https:// form.

Server started by hand (uvicorn main:app ...): the line Pairing page ... /setup?token=... is in the terminal where it runs; open http://127.0.0.1:{{ port }}/setup?token=... on that machine, or run python3 setup.py there to print the codes.

The token changes every time the server starts.
