Pairing page is local only

This page shows both secret keys, so the server only serves it to a browser running on the server itself.

On the server open http://127.0.0.1:{{ port }}/setup, or run python3 setup.py in a terminal to print the QR codes there.

From another machine you can tunnel it with ssh -L {{ port }}:127.0.0.1:{{ port }} user@server and open the same address.
